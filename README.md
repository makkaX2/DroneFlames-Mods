## 🛠️ Структура модификации (.dfmod)

Модификация представляет собой обычный ZIP-архив с расширением `.dfmod` (либо распакованную папку в директории `mods/`), содержащий следующие обязательные и опциональные файлы:

```text
mods/my_awesome_mod/
├── mod.json          # Обязательно: манифест и метаданные мода
├── mod.gd            # Обязательно/Опционально: входной GDScript скрипт
├── icon.png          # Иконка мода для отображения в списке (64x64 или 128x128)
└── assets/           # Текстуры, звуки, кастомные ресурсы (опционально)
```

---

## 📄 Спецификация `mod.json`

Файл `mod.json` описывает параметры мода, его версию и возможности:

```json
{
  "id": "oasis_map",
  "name": "Карта: Оазис в Пустыне",
  "version": "1.0.0",
  "author": "good_boy_irl",
  "type": "map",
  "description": "Новый тип карты: бескрайняя песчаная пустыня с плодородными оазисами и нефтяными вышками.",
  "details": "Добавляет в меню выбора карт новый уникальный тип ландшафта 'ПУСТЫНЯ'.\n• 85% песчаных дюн и каньонов\n• Оазисы вокруг водоёмов с пресной водой\n• Богатые залежи нефти и редких руд\n• Подходит для одиночной игры и мультиплеера",
  "entry": "mod.gd",
  "icon": "icon.png",
  "tags": ["карта", "пустыня", "биом", "оазис"],
  "min_game_version": "0.33.2"
}
```

### Поддерживаемые типы модов (`type`):
- `map` — Новые типы карт, биомы, генераторы ландшафта и сценарии размещения.
- `ui` — Новые разделы интерфейса, окна статистики, кастомные хабы и вкладки меню.
- `textures` — Текстурпаки, замена спрайтов техники, новые стили городов и значков.
- `gameplay` — Новые юниты, параметры баланса, экономические и дипломатические механики.

## 💻 Пример скрипта `mod.gd`

Скрипт мода реализует методы жизненного цикла: `init_mod(mod_mgr)` при активации и `cleanup_mod(mod_mgr)` при отключении:

```gdscript
extends RefCounted

var _registered_map_id: String = ""

func init_mod(mod_mgr: Node) -> void:
    print("[Desert Oasis Mod] Mod initialized!")
    
    # Регистрация нового типа карты
    _registered_map_id = "desert_oasis"
    mod_mgr.register_map_type({
        "id": _registered_map_id,
        "name": "ПУСТЫНЯ",
        "hint": "Бескрайняя суша: редкие оазисы, жара и борьба за нефть",
        "icon": "map_t_normal", # либо кастомная текстура
        "land_percent": 82,
        "generator": Callable(self, "_generate_desert_map")
    })

func cleanup_mod(mod_mgr: Node) -> void:
    print("[Desert Oasis Mod] Mod cleaned up!")
    if _registered_map_id != "":
        mod_mgr.unregister_map_type(_registered_map_id)
```

## 📦 Как упаковать мод в `.dfmod`

1. Соберите все файлы мода (`mod.json`, `mod.gd`, `icon.png` и папку `assets/`).
2. Запакуйте их в обычный ZIP-архив (файлы должны находиться в корне архива, без лишней внешней папки).
3. Переименуйте расширение архива с `.zip` на `.dfmod`.
4. Готово! Файл `.dfmod` можно передать игроку или положить в папку `mods/` в игре.

## 🗂️ Где находятся моды на компьютере игрока

- **AppData:** `%APPDATA%\Godot\app_userdata\DroneFlames (PC Port by @good_boy_irl)\mods\`
- **Портативная версия:** Папка `mods\` рядом с исполняемым файлом `DroneFlames.exe`.
- **В игре:** Раздел **«МОДИФИКАЦИИ»** в главном меню (кнопка *«Открыть папку модов»* откроет каталог в Проводнике Windows).
